# Snack&Go - Página Web de Restaurante

Una página web moderna, minimalista y completamente responsive para el restaurante de comida rápida "Snack&Go" en Madrid.

## 🚀 Características Principales

- **Diseño Profesional**: Interfaz minimalista con video hero y efectos visuales elegantes
- **100% Responsive**: Adaptación perfecta para desktop, tablet y móviles (320px - 1920px+)
- **Imágenes Locales**: Todas las imágenes almacenadas localmente para máxima velocidad
- **Menú Hamburguesa Profesional**: Navegación lateral elegante con animaciones suaves
- **Animaciones al Scroll**: Elementos aparecen suavemente al hacer scroll
- **Indicador de Progreso**: Barra superior que muestra el progreso de scroll
- **Efectos Hover Avanzados**: Transiciones profesionales en todos los elementos
- **Optimizado para Móviles**: Touch targets, gestos y UX específica para móviles
- **SEO Optimizado**: Meta tags, estructura semántica y performance optimizada

## 📱 Secciones Implementadas

1. **Hero Section**: Video de fondo con texto superpuesto y estadísticas
2. **Nuestra Filosofía**: Video de tacos mexicanos y descripción empresarial
3. **Menú Visual**: 6 categorías con imágenes circulares y precios
   - Hamburguesas (3 productos)
   - Kebabs (3 productos) 
   - Burritos (3 productos)
   - Patatas & Snacks (3 productos)
   - Bebidas (4 productos)
   - Combos Especiales (3 productos)
4. **Productos Destacados**: 3 platos principales con badges y calorías
5. **Encuéntranos**: Mapa interactivo con información de contacto
6. **Contacta con Nosotros**: 4 métodos de contacto (teléfono, email, ubicación, WhatsApp)
7. **Footer Completo**: Información legal, redes sociales y créditos del desarrollador

## 🎨 Diseño

- **Colores**: Paleta minimalista con negro, blanco y rojo (#e74c3c) como color acento
- **Tipografía**: Poppins (Google Fonts) para una lectura clara y moderna
- **Elementos**: Bordes redondeados, sombras suaves y efectos hover
- **Iconos**: Font Awesome para iconografía consistente

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica con meta tags optimizados para móviles
- **CSS3**: Flexbox, Grid, animaciones cubic-bezier y media queries avanzadas
- **JavaScript ES6+**: Intersection Observer, touch events y optimizaciones móviles
- **Google Fonts**: Tipografía Poppins (300, 400, 600, 700)
- **Font Awesome 6.0**: Iconografía completa y consistente
- **Imágenes Locales**: Todas las imágenes almacenadas en carpeta `/images/`
